# Peer Interview Rubric

Use this rubric when you're the "interviewer" in a mock interview breakout. Check off each item the interviewee demonstrates, and leave a short note. This is real feedback for your partner, not just a grade — talk them through it before you submit.

**Interviewer:** once you're done, submit this rubric via the [Peer Interview Rubric form](https://forms.gle/m8j2nLWB3HbgnGGx9) — note the lesson number and your partner's name. This is what counts toward their 6-of-8.

## Communication (check all that apply)

- [ ] Restated the problem in their own words
- [ ] Asked at least one relevant clarifying question
- [ ] Stated assumptions about input/output explicitly
- [ ] Thought out loud while working, not silently
- [ ] Explained their rationale for the approach chosen
- [ ] Discussed at least one tradeoff (time vs. space, simplicity vs. performance, etc.)
- [ ] Suggested an improvement or alternative after reaching a working solution

## Problem Solving

- [ ] Came up with test inputs before or while coding, not only at the end
- [ ] Found a pattern or simplified version of the problem before jumping to code
- [ ] Wrote pseudocode (or clearly structured their approach) before full code
- [ ] Tested the solution against good/normal, bad/unusual, and edge case inputs
- [ ] Correctly identified the time/space complexity of their solution

## AI Tool Use (if applicable to this round)

- [ ] Disclosed AI tool use clearly, if any was used or allowed
- [ ] Could explain every part of their own solution when asked, regardless of how it was produced

## Behavioral (STAR) — if applicable to this round

- [ ] Named a specific, real situation — not vague or generic
- [ ] Described their own individual action ("I," not just "we")
- [ ] Gave a clear result, ideally with a measurable outcome
- [ ] Answer was appropriately concise — not rambling, not too short
- [ ] Actually answered the question asked, didn't drift off-topic
