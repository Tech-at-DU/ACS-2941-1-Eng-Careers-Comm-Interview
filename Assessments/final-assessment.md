# Final Assessment Study Guide

The final assessment is a mock technical interview covering the full loop: a communication + coding round and a behavioral round. Use this guide to review each learning outcome from the course. For each item, be able to both *explain* the concept and *demonstrate* it live.

## Communication & Problem Solving

- Restate a problem in your own words before attempting a solution
- Ask 2-3 relevant clarifying questions for an unfamiliar prompt
- State your assumptions about input format, size, and edge behavior explicitly
- Think out loud: brainstorm more than one approach, explain your rationale, discuss tradeoffs, and suggest improvements after a working solution
- Apply the full problem-solving sequence: generate test inputs → understand/simplify the problem → find a pattern → pseudocode → code → test
- Generate good/normal, bad/unusual, and edge case test inputs for a given problem

## Coding Fundamentals

- Recognize and fix common syntax errors and convention violations in JavaScript and Python
- Trace code by hand using a variable table, without running it
- Analyze time and space complexity (Big O) for a given solution and explain the tradeoffs between approaches

## AI Tool Fluency

- Explain when AI coding assistance is expected, allowed-with-disclosure, or banned across different interview formats
- Disclose AI tool use honestly and concisely, without over-apologizing or over-explaining
- Explain and defend code — including code you didn't write yourself — under direct questioning

## Behavioral

- Use the STAR method (Situation, Task, Action, Result) to answer a behavioral question
- Answer the most common behavioral question categories: teamwork, conflict, failure, initiative, learning quickly, prioritization
- Give a clear, specific answer to "Why do you want to work here?"

## Career Materials

- Explain what makes a resume bullet effective (action verb + outcome, not just a responsibility)
- Walk through a portfolio project end-to-end: what it does, your specific contributions, what was hard, what you'd change
- Describe how you'd research and reach out to an industry contact for an informational interview

## Format

- Mock interview, ~30 minutes, one communication/coding problem and 2-3 behavioral questions
- Graded using the same peer interview rubric used throughout the course (see [Assignments/Sample_Rubric.md](../Assignments/Sample_Rubric.md))
- You will also submit your final Video Interview assignment (see [Assignments/Video-Interview.md](../Assignments/Video-Interview.md)) as part of the final grade
